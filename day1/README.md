# Day 1 - Git and GitHub Basics

## Overview

This repository contains the tasks completed on Day 1 of learning Git and GitHub. The objective was to set up the development environment, initialize a local Git repository, create a GitHub repository, and push local code to GitHub.

## Development Setup

### Tools Installed

* Git
* Visual Studio Code (VS Code)
* GitHub 
* Web Browser

## Git Commands Used

### Initialize a Local Repository

```bash
git init
```

### Check Repository Status

```bash
git status
```

### Stage Files

```bash
git add .
```

### Commit Changes

```bash
git commit -m "Initial commit"
```

### Connect Local Repository to GitHub

```bash
git remote add origin <repository-url>
```

### Push Code to GitHub

```bash
git push -u origin main
```

## What I Learned

* How to initialize a local Git repository.
* The difference between working directory, staging area, and commits.
* How to track changes using Git.
* How to create commits with meaningful messages.
* How to create a repository on GitHub.
* How to connect a local repository to a remote repository.
* How to push code from a local machine to GitHub.

## Outcome

Successfully created a local Git repository, committed changes, created a GitHub repository, and pushed the project to GitHub.
