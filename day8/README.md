# Day 8 - JavaScript Core Concepts

## Concepts Covered

### 1. Variables

JavaScript uses `let` and `const` to declare variables.



* `let` allows reassignment.
* `const` cannot be reassigned.

---

### 2. Primitive Data Types

JavaScript primitive data types include:

* String
* Number
* Boolean
* Undefined
* Null
* Symbol



---

### 3. Control Flow

Control flow determines which code executes.

#### If-Else



#### Loops

```javascript
for(let i = 1; i <= 5; i++){
    console.log(i);
}
```

---

### 4. Functions

#### Function Declaration

```javascript
function greet(){
    console.log("Hello");
}
```

#### Arrow Function

```javascript
const greet = () => {
    console.log("Hello");
};
```

---



### 5. Arrays

Arrays store multiple values.

```javascript
const numbers = [1,2,3,4,5];
```

---

### 6. Objects

Objects store data as key-value pairs.

```javascript
const student = {
    name: "Aisha",
    age: 30
};
```

---



## Key Learnings

* Difference between `let` and `const`
* Primitive data types in JavaScript
* Control flow using conditions and loops
* Function declarations and arrow functions
* Local and global scope
* Arrays and objects
